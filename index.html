Deploy SIPANTAU di GitHub

Aplikasi SIPANTAU menggunakan Vite + React. Agar halaman web muncul sempurna tanpa error 404, aktifkan GitHub Actions pada pengaturan repositori:

Langkah Mengaktifkan di GitHub:

  1. Buka repository Anda di GitHub
  2. Klik menu Settings → pilih Pages (di sidebar kiri)
  3. Pada bagian Build and deployment, ubah Source dari Deploy from a branch menjadi GitHub Actions
  4. Tunggu 1 menit hingga proses deploy otomatis selesai
